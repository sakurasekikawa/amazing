## Why MIT

This project's reusable part (the `mazegen` package) is explicitly meant to
be installed and built upon by later 42 projects (subject, Chapter VI). MIT
was chosen because it is short, widely understood, and places no
restriction beyond keeping the copyright notice -- it unambiguously allows
reuse, modification and redistribution, which is exactly what a later
project needs to be able to do with this code.
